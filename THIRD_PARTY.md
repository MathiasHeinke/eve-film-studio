# Third-party references and dependencies

The FCPXML integration uses the separately installed [fcp-mcp-server](https://github.com/DareDev256/fcp-mcp-server), an MIT-licensed project. This repository includes an example configuration, an original verification helper and a tested dependency list; it does not vendor the server or its dependencies.

FFmpeg, Fontconfig, librsvg, Python and the other tools named in the skills are installed separately and retain their own licenses. Generation providers, editors and linked documentation retain their own terms.

No third-party film footage, music, fonts, customer assets, model weights or commercial editor binaries are distributed here. Obtain appropriate rights for assets used in a production.
